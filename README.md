# MiniMuscu

MiniMuscu est une petite PWA de musculation pensée pour faire un circuit rapide chaque jour, directement depuis le navigateur.

## Fonctionnalités

- Programme d’entraînement journalier
- Circuits courts sans matériel
- Mode séance avec exercice en cours
- Chronomètre pour les exercices temporisés
- Validation du circuit du jour
- Sauvegarde locale avec `localStorage`
- Installation possible comme PWA

## Objectif

Avoir une app ultra simple pour garder une routine sportive régulière, sans compte utilisateur, sans backend, et sans matériel.

## Installation

```bash
npm install
npm run dev
npm run build
```
